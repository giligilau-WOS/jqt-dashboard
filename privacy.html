隱私權政策

最後更新日期：2026-11-22｜應用程式網址：https://giligilau-wos.github.io/jqt-dashboard/

「2611王國 · 戰情室」（jqt-dashboard，以下簡稱「本服務」）為提供 2611 王國玩家與聯盟幹部進行名冊檢視、活動報名（兵工廠、峽谷會戰、太陽城、雪域兵器聯賽、霜龍霸主）、分隊排程與戰力排行瀏覽之社群管理工具。本政策說明本服務如何蒐集、使用及保護您的資料。

1. 本服務蒐集與處理的資料

  • 遊戲角色與活動報名資料：由玩家或王國幹部主動提供或同步之遊戲資訊，包含角色名稱、遊戲編號（FID）、所屬聯盟、戰力、熔爐等級、活動報名選項及分隊安排。本服務不會要求您提供遊戲帳號密碼。
  • 瀏覽器本機儲存（LocalStorage）：本服務僅於您的瀏覽器本機儲存介面偏好設定（例如深色／淺色主題）與幹部／管理員之登入狀態，不會用於跨站追蹤或廣告投放。
  • Google API 與 Google 帳號授權資料（若啟用 OAuth 登入或連結）：當管理員或授權使用者透過 Google OAuth 授權本服務存取 Google 試算表（Google Sheets）或 Google Apps Script 服務時，本服務僅在授權範圍內存取該王國管理用試算表之名冊與活動資料，以及驗證操作者身分所需之基本帳號資訊。

2. 資料使用方式

  • 顯示王國名冊、排行榜與各活動報名狀態。
  • 協助王國與聯盟幹部進行活動分隊、名單鎖定與資料同步。
  • 本服務不會出售、出租或向任何第三方廣告商揭露您的個人資料或 Google API 授權資料。

3. Google API 服務使用者資料政策遵循聲明

本服務對從 Google API 接收之任何資訊的使用與傳輸，均完全遵守 Google API 服務使用者資料政策（Google API Services User Data Policy），包含其中的「限制使用（Limited Use）」規定。本服務不會將透過 Google API 取得之資料用於訓練通用 AI／機器學習模型或非本服務功能以外之用途。

4. 資料保存與刪除

  • 您可隨時在瀏覽器清除本網站之 localStorage 資料。
  • 若您曾授予 Google 帳號權限，可隨時前往 Google 帳戶第三方應用程式存取權 撤銷對本服務的授權。
  • 如需查詢、更正或刪除您在王國名冊中的遊戲角色資料，請聯繫王國管理員，或透過本專案 GitHub 頁面提出申請。

5. 聯絡方式

若您對本隱私權政策有任何疑問，請透過 GitHub 專案頁面聯繫開發與維護團隊：https://github.com/giligilau-WOS/jqt-dashboard

Privacy Policy (English Summary)

Last Updated: 2026-11-22 | App URL: https://giligilau-wos.github.io/jqt-dashboard/

2611 Kingdom Dashboard (jqt-dashboard) is a community management tool for State 2611 players and alliance officers to manage kingdom rosters, event signups, squad assignments, and leaderboards.

  • Data Processed: Game profile data (in-game nickname, game ID/FID, alliance, combat power, furnace level, event signup records), local browser preferences (localStorage), and Google Sheets / Google Apps Script data strictly within the scope authorized by the administrator.
  • Data Usage: Data is used solely to display kingdom rosters, record event registrations, and coordinate alliance/kingdom events. We do not sell, rent, or share user data with third-party advertisers.
  • Google API Limited Use Compliance: The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revocation & Deletion: You may revoke Google OAuth access at any time via Google Account Permissions, clear local browser storage, or request data removal via github.com/giligilau-WOS/jqt-dashboard.
